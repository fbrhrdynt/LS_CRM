About

Built for practical inventory operations.

LS Inventory combines physical inventory identification, user authentication and cloud synchronization into a simple inventory terminal designed for internal operational use.

◉

RFID / NFC Authentication

Authorized users identify themselves using registered NFC or RFID cards before performing inventory operations.

▦

QR Item Identification

Inventory items use unique QR codes and UUID identifiers to provide consistent item identification.

⇄

Borrow & Return

Track borrowed equipment, current borrower information, return activity, and transaction timestamps.

−

Consumable Management

Record consumable usage, automatically reduce stock and monitor low-stock or out-of-stock conditions.

☁

Cloud Synchronization

Authorized inventory information and transactions are synchronized with Google Sheets.

↻

Offline Queue

Transactions can be temporarily stored locally when connectivity is unavailable and synchronized when access is restored.

API

Google Sheets Integration

LS Inventory uses the Google Sheets API to access only the Google Spreadsheet explicitly authorized by the system administrator. The integration is used exclusively for inventory management functionality.

✓
Inventory Items Read and update inventory item status, stock and item information.
✓
Authorized Users Read user records required for NFC/RFID identification.
✓
Transaction Records Store Borrow, Return and Consumable transaction records.
✓
System Configuration Read authorized system settings used by the LS Inventory device.
Privacy & Security

Designed for controlled internal use.

LS Inventory processes only the information required to operate inventory management functionality.

No Advertising

Google user data is not used for advertising, behavioral profiling, or marketing purposes.

No Sale of Data

LS Inventory does not sell Google user data or inventory information to third parties.

Restricted Access

Inventory operations are intended for authorized users and authorized LS Inventory devices.
